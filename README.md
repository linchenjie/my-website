# 汉本养 IP 创作工作台

直接在浏览器中打开 `index.html`，无需安装依赖。页面适配电脑和手机。

公开网站：https://linchenjie.github.io/my-website/

GitHub Pages 使用 `main` 分支根目录发布。网站上的创作数据仍仅保存在访问者自己的浏览器中。

## 已实现

- 工作台：收藏、脚本、对标与未来 7 天计划的实际统计。
- 对标与灵感：选题筛选、城市筛选、收藏、收录公开抖音作品链接和手动互动数据。
- 口播创作：按表达方向生成模板初稿，补充经历，编辑、复制、保存。
- 发布日历：按月浏览、新建、编辑、删除计划和标记完成。
- 内容库：查看收藏、编辑和删除脚本。
- IP 设置：名称、城市、客群、定位、标签；JSON 备份导出和合并导入。
- AI 封面与配图：Nano Banana 2 异步生图、参考图直链、比例选择、任务进度查询、结果预览及原图保存入口。

## 生图接口

按 https://xjjuhe.site/docs/nano-banana 接入：`POST /v1/videos` 提交 `nano_banana_2`，`GET /v1/videos/:id` 每 3 秒查询结果。这是生图接口，返回图片，不是视频。

GitHub Pages 不运行后端，平台当前也未对浏览器返回跨域许可。项目附带无第三方依赖的 Node.js 中转服务：

```sh
npm start
```

打开 `http://127.0.0.1:8787/#images`。在页面填写 xjjuhe 控制台的 API Key，不能使用 GitHub 的 `ghp_` 令牌。密钥仅保留在页面内存，并通过请求头转发给平台；不会写入 localStorage、备份或仓库。刷新页面需要重新填写。

公开网站需要单独部署 `server.mjs` 到支持 Node.js 22+ 的服务器，设置 `HOST=0.0.0.0`、`PORT` 和 `ALLOWED_ORIGINS=https://linchenjie.github.io`，配置 HTTPS，然后在页面的中转服务地址中填写该服务域名。中转仅转发调用者提供的密钥，不配置共享的付费密钥。

服务仅代理固定的 xjjuhe 生图接口，限制模型、参数和请求体大小，并屏蔽上游原始错误。不要把 API Key 写入前端、公开环境配置或提交到 GitHub。页面中的任务会保存在当前浏览器，密钥不会保存。成功生成按平台规则计费；任务失败或网络中断时先查询已有任务，避免重复提交。

验证：`npm test` 检查代理参数、任务查询、鉴权拒绝、跨域限制和错误脱敏。没有有效的平台 API Key 时，不能验证真实付费生成。

## 数据范围

数据存储在当前浏览器的 localStorage。不同浏览器、设备之间不会同步。使用前可在设置中导出备份。

首次打开的选题是原创示例，没有伪造播放量、点赞量或真实品牌作品。图库图片不是汉本养实际门店、产品或员工照片。

口播生成使用本地模板，不调用大模型。作品收录不会下载视频或自动获取互动数据，也不会自动发布。用户提供的解析接口尚未确认文档与授权方式，没有接入。要成为多人使用的线上后台，还需配置服务器、账号、数据库与获授权的数据来源。
